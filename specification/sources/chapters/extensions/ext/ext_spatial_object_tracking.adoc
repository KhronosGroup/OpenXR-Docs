==== Overview

This extension builds on apiext:XR_EXT_spatial_entity and defines a spatial
capability for tracking a set of predefined objects without requiring an
input dataset from the application.

==== Runtime Support

If the runtime supports object tracking, it must: indicate this by
enumerating ename:XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT in
flink:xrEnumerateSpatialCapabilitiesEXT.

If the runtime enumerates apiext:XR_EXT_spatial_object_tracking in
flink:xrEnumerateInstanceExtensionProperties, it must: also enumerate
apiext:XR_EXT_spatial_entity_archetypes.
However, the runtime must: not return any error from flink:xrCreateInstance
if the application enables apiext:XR_EXT_spatial_object_tracking without
enabling apiext:XR_EXT_spatial_entity_archetypes.

[[ext_spatial_object_tracking_guaranteed_components]]
==== Guaranteed Components

A runtime that supports ename:XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT,
must: support the following spatial components as guaranteed components of
the entities discovered by this capability and must: enumerate them in
flink:xrEnumerateSpatialCapabilityComponentTypesEXT:

* ename:XR_SPATIAL_COMPONENT_TYPE_BOUNDED_3D_EXT
* At least one component type that provides a set of semantic label for the
  tracked objects.
  An object tracking capability is meaningless without a semantic label
  component.
  While this extension defines
  ename:XR_SPATIAL_COMPONENT_TYPE_OBJECT_SEMANTIC_LABEL_EXT,
  ename:XR_SPATIAL_COMPONENT_TYPE_KEYBOARD_SEMANTIC_LABEL_EXT, and
  ename:XR_SPATIAL_COMPONENT_TYPE_MOUSE_SEMANTIC_LABEL_EXT as possible
  semantic label components for runtimes to support, other extensions may:
  define new component types to provide different classes of semantic labels
  that describe a tracked object.
  See <<ext_spatial_entity_semantic_labels_guidelines>> for details about
  the semantic label sets and component types design.
  Runtimes are not required to support either of
  ename:XR_SPATIAL_COMPONENT_TYPE_OBJECT_SEMANTIC_LABEL_EXT,
  ename:XR_SPATIAL_COMPONENT_TYPE_KEYBOARD_SEMANTIC_LABEL_EXT, or
  ename:XR_SPATIAL_COMPONENT_TYPE_MOUSE_SEMANTIC_LABEL_EXT for the object
  tracking capability but must: support at least one component type that
  provides a semantic label.

===== Bounded 3D Component

The bounded 3D component provides the center and extents of the object
represented by the entity it is on.
See <<ext_spatial_entity_bounded3D_component>> for more details.

==== Optional Components

A runtime that supports ename:XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT,
may: support spatial components in addition to the ones listed in the
<<ext_spatial_object_tracking_guaranteed_components>> section.
The application can: use flink:xrEnumerateSpatialCapabilityComponentTypesEXT
to get the full list of components that a runtime supports and can: then
configure the ones it is interested in when creating the spatial context.

===== Object Semantic Label

====== Component data

[open,refpage='XrSpatialObjectSemanticLabelEXT',type='enums',desc='Object semantic label',xrefs='XrSpatialComponentObjectSemanticLabelListEXT']
--
include::{generated}/api/enums/XrSpatialObjectSemanticLabelEXT.adoc[]

The elink:XrSpatialObjectSemanticLabelEXT enumeration describes a set of
semantic labels for objects.

For entities with the
ename:XR_SPATIAL_OBJECT_SEMANTIC_LABEL_DISPLAY_SCREEN_EXT label, the +Z axis
of the <<ext_spatial_entity_bounded3D_component>> component must: roughly
match the surface normal of the screen.

For entities with the ename:XR_SPATIAL_OBJECT_SEMANTIC_LABEL_WALL_ART_EXT
label, the +Z axis of the <<ext_spatial_entity_bounded3D_component>>
component must: match the surface normal of the wall the art is discovered
on.

For entities with the ename:XR_SPATIAL_OBJECT_SEMANTIC_LABEL_TABLE_EXT
label, the +Z axis of the <<ext_spatial_entity_bounded3D_component>>
component must: match the surface normal of the table.

For all the other labels in elink:XrSpatialObjectSemanticLabelEXT, the
application must: not make any assumptions about how the
slink:XrBoxf::pname:center::pname:orientation provided by the
<<ext_spatial_entity_bounded3D_component>> component on the entity aligns
with the physical attributes of that object.

==== Example code

===== Configure Object Tracking Capability

The following example code demonstrates how to configure object tracking
capability when creating a spatial context.

[source,cpp]
----
// Check if object tracking capability is supported
uint32_t capabilityCount = 0;
CHK_XR(xrEnumerateSpatialCapabilitiesEXT(instance, systemId, 0, &capabilityCount, nullptr));
std::vector<XrSpatialCapabilityEXT> capabilities(capabilityCount);
CHK_XR(xrEnumerateSpatialCapabilitiesEXT(instance, systemId, capabilityCount, &capabilityCount, capabilities.data()));

if (std::find(capabilities.begin(), capabilities.end(), XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT) == capabilities.end()) {
  return;
}

// Enumerate supported components for object tracking capability
XrSpatialCapabilityComponentTypesEXT objectComponents {
  .type = XR_TYPE_SPATIAL_CAPABILITY_COMPONENT_TYPES_EXT,
};
CHK_XR(xrEnumerateSpatialCapabilityComponentTypesEXT(instance, systemId, XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT, &objectComponents));
std::vector<XrSpatialComponentTypeEXT> objectCapabilityComponents(objectComponents.componentTypeCountOutput);
objectComponents.componentTypeCapacityInput = objectCapabilityComponents.size();
objectComponents.componentTypes = objectCapabilityComponents.data();
CHK_XR(xrEnumerateSpatialCapabilityComponentTypesEXT(instance, systemId, XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT, &objectComponents));

// Check if the object & keyboard semantic labels component is supported
const auto supportsComponent = [&objectCapabilityComponents](XrSpatialComponentTypeEXT component) {
  return std::find(objectCapabilityComponents.begin(), objectCapabilityComponents.end(), component) != objectCapabilityComponents.end();
};

const bool supportsObjectSemanticLabel = supportsComponent(XR_SPATIAL_COMPONENT_TYPE_OBJECT_SEMANTIC_LABEL_EXT);
const bool supportsKeyboardSemanticLabel = supportsComponent(XR_SPATIAL_COMPONENT_TYPE_KEYBOARD_SEMANTIC_LABEL_EXT);

// Enumerate supported features for object tracking capability
uint32_t featureCount;
CHK_XR(xrEnumerateSpatialCapabilityFeaturesEXT(instance, systemId, XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT, 0, &featureCount, nullptr));
std::vector<XrSpatialCapabilityFeatureEXT> features(featureCount);
CHK_XR(xrEnumerateSpatialCapabilityFeaturesEXT(instance, systemId, XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT, featureCount, &featureCount, features.data()));

const bool supportsObjectSemanticLabelSubsetFeature = std::find(features.begin(), features.end(), XR_SPATIAL_CAPABILITY_FEATURE_OBJECT_SEMANTIC_LABEL_SUBSET_EXT) != features.end();

// Create a spatial context
XrSpatialContextEXT spatialContext{};

// Enable the guaranteed components of the object tracking capability
std::vector<XrSpatialComponentTypeEXT> enabledComponents = {
  XR_SPATIAL_COMPONENT_TYPE_BOUNDED_3D_EXT,
};
// Optionally enable the supported semantic labels
if (supportsObjectSemanticLabel) {
  enabledComponents.push_back(XR_SPATIAL_COMPONENT_TYPE_OBJECT_SEMANTIC_LABEL_EXT);
}
if (supportsKeyboardSemanticLabel) {
  enabledComponents.push_back(XR_SPATIAL_COMPONENT_TYPE_KEYBOARD_SEMANTIC_LABEL_EXT);
}

// We only want to track sofa and table.
std::vector<XrSpatialObjectSemanticLabelEXT> objectSemanticLabelSubset = {
  XR_SPATIAL_OBJECT_SEMANTIC_LABEL_SOFA_EXT,
  XR_SPATIAL_OBJECT_SEMANTIC_LABEL_TABLE_EXT
};
XrSpatialFeatureObjectSemanticLabelSubsetEXT subsetFeature {
  .type = XR_TYPE_SPATIAL_FEATURE_OBJECT_SEMANTIC_LABEL_SUBSET_EXT,
  .semanticLabelCount = static_cast<uint32_t>(objectSemanticLabelSubset.size()),
  .semanticLabels = objectSemanticLabelSubset.data(),
};

XrSpatialCapabilityConfigurationObjectTrackingEXT objectTrackingConfig {
  .type = XR_TYPE_SPATIAL_CAPABILITY_CONFIGURATION_OBJECT_TRACKING_EXT,
  .next = supportsObjectSemanticLabelSubsetFeature ? &subsetFeature : nullptr,
  .capability = XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT,
  .enabledComponentCount = static_cast<uint32_t>(enabledComponents.size()),
  .enabledComponents = enabledComponents.data(),
};

std::array<XrSpatialCapabilityConfigurationBaseHeaderEXT*, 1> capabilityConfigs = {
  reinterpret_cast<XrSpatialCapabilityConfigurationBaseHeaderEXT*>(&objectTrackingConfig),
};

XrSpatialContextCreateInfoEXT spatialContextCreateInfo {
  .type = XR_TYPE_SPATIAL_CONTEXT_CREATE_INFO_EXT,
  .capabilityConfigCount = static_cast<uint32_t>(capabilityConfigs.size()),
  .capabilityConfigs = capabilityConfigs.data(),
};
XrFutureEXT createContextFuture {XR_NULL_FUTURE_EXT};
CHK_XR(xrCreateSpatialContextAsyncEXT(session, &spatialContextCreateInfo, &createContextFuture));

waitUntilReady(createContextFuture);

XrCreateSpatialContextCompletionEXT completion {
  .type = XR_TYPE_CREATE_SPATIAL_CONTEXT_COMPLETION_EXT,
};
CHK_XR(xrCreateSpatialContextCompleteEXT(session, createContextFuture, &completion));
if (completion.futureResult != XR_SUCCESS) {
  return;
}

spatialContext = completion.spatialContext;

// ...
// Discover entities with the spatial context
// ...

CHK_XR(xrDestroySpatialContextEXT(spatialContext));
----

===== Discover Spatial Entities & Query Component Data

The following example code demonstrates how to discover spatial entities for
a context configured with ename:XR_SPATIAL_CAPABILITY_OBJECT_TRACKING_EXT
and query its component data.

[source,cpp]
----
XrFutureEXT future {XR_NULL_FUTURE_EXT};

// We want to look for entities that have the following components.
std::vector<XrSpatialComponentTypeEXT> snapshotComponents = {
  XR_SPATIAL_COMPONENT_TYPE_BOUNDED_3D_EXT,
};
if (supportsKeyboardSemanticLabel) {
  snapshotComponents.push_back(XR_SPATIAL_COMPONENT_TYPE_KEYBOARD_SEMANTIC_LABEL_EXT);
}

auto discoverSpatialEntities = [&](XrSpatialContextEXT spatialContext, XrTime time) {
  XrSpatialDiscoverySnapshotCreateInfoEXT snapshotCreateInfo {
    .type = XR_TYPE_SPATIAL_DISCOVERY_SNAPSHOT_CREATE_INFO_EXT,
    .componentTypeCount = static_cast<uint32_t>(snapshotComponents.size()),
    .componentTypes = snapshotComponents.data(),
  };
  CHK_XR(xrCreateSpatialDiscoverySnapshotAsyncEXT(spatialContext, &snapshotCreateInfo, &future));

  waitUntilReady(future);

  XrCreateSpatialDiscoverySnapshotCompletionInfoEXT completionInfo {
    .type = XR_TYPE_CREATE_SPATIAL_DISCOVERY_SNAPSHOT_COMPLETION_INFO_EXT,
    .baseSpace = localSpace,
    .time = time,
    .future = future,
  };

  XrCreateSpatialDiscoverySnapshotCompletionEXT completion {
    .type = XR_TYPE_CREATE_SPATIAL_DISCOVERY_SNAPSHOT_COMPLETION_EXT,
  };
  CHK_XR(xrCreateSpatialDiscoverySnapshotCompleteEXT(spatialContext, &completionInfo, &completion));
  if (completion.futureResult == XR_SUCCESS) {

    // Query for the semantic label component data
    XrSpatialComponentDataQueryConditionEXT queryCond {
      .type = XR_TYPE_SPATIAL_COMPONENT_DATA_QUERY_CONDITION_EXT,
      .componentTypeCount = static_cast<uint32_t>(snapshotComponents.size()),
      .componentTypes = snapshotComponents.data(),
    };

    XrSpatialComponentDataQueryResultEXT queryResult {
      .type = XR_TYPE_SPATIAL_COMPONENT_DATA_QUERY_RESULT_EXT,
    };
    CHK_XR(xrQuerySpatialComponentDataEXT(completion.snapshot, &queryCond, &queryResult));

    std::vector<XrSpatialEntityIdEXT> entityIds(queryResult.entityIdCountOutput);
    std::vector<XrSpatialEntityTrackingStateEXT> entityStates(queryResult.entityIdCountOutput);
    queryResult.entityIdCapacityInput = entityIds.size();
    queryResult.entityIds = entityIds.data();
    queryResult.entityStateCapacityInput = entityStates.size();
