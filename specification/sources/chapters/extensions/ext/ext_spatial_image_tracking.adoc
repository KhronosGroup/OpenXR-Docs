==== Overview

This extension provides the image tracking capability for the
<<XR_EXT_spatial_entity>> extension.
It enables applications to detect and track specific planar images as
specified by sets of input reference images.

A tracked image is represented as a spatial entity with (or "that has") the
following components:

* ename:XR_SPATIAL_COMPONENT_TYPE_IMAGE_2D_EXT
* ename:XR_SPATIAL_COMPONENT_TYPE_BOUNDED_2D_EXT

Applications typically use the spatial image tracking extension in the
following pattern:

* An application first creates one or many
  slink:XrSpatialImageTrackingDatabaseEXT handles based on sets of preloaded
  reference image data.

* The application then creates an slink:XrSpatialContextEXT handle based on
  the slink:XrSpatialImageTrackingDatabaseEXT handles created previously.

* The application then releases the reference image data to reduce its
  memory consumption.

* The application discovers and queries images according to the spatial
  entity access patterns.

* The application can: load additional sets of reference images and create
  additional slink:XrSpatialImageTrackingDatabaseEXT and subsequently
  slink:XrSpatialContextEXT from them to extend the set of detectable and
  trackable images dynamically at runtime.

* The application can: destroy slink:XrSpatialImageTrackingDatabaseEXT
  handles to reduce the set of detectable and trackable images dynamically
  at runtime.

* The application can: destroy slink:XrSpatialContextEXT handles to reduce
  the set of detectable and trackable images dynamically at runtime.

==== Runtime Support

A runtime must: advertise its support for the image tracking capability
using flink:xrEnumerateSpatialCapabilitiesEXT by listing the following
capability:

* ename:XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT

==== Configuration

To enable detection and tracking of planar images, the application can: pass
slink:XrSpatialCapabilityConfigurationImageTrackingEXT structures in
slink:XrSpatialContextCreateInfoEXT::pname:capabilityConfigs when calling
the flink:xrCreateSpatialContextAsyncEXT function, and passing arrays of
slink:XrSpatialImageTrackingDatabaseEXT structures in each
slink:XrSpatialCapabilityConfigurationImageTrackingEXT::pname:imageTrackingDatabases.

==== Input Image Set Creation

To specify the reference images to be detected and tracked, the application
must: create at least one set of input reference images.
A set of input reference images is represented by an
slink:XrSpatialImageTrackingDatabaseEXT handle and contains at least one
image.

[open,refpage='XrSpatialImageTrackingDatabaseEXT',type='handles',desc='Represents a spatial image tracking database.']
--
include::{generated}/api/handles/XrSpatialImageTrackingDatabaseEXT.adoc[]

The slink:XrSpatialImageTrackingDatabaseEXT handle represents the resources
for discovering and updating some number of spatial images in the
environment of the user.
Applications can: use this handle to discover and update spatial images
using other functions in this extension.

===== Destroy the Spatial Image Tracking Database

[open,refpage='xrDestroySpatialImageTrackingDatabaseEXT',type='protos',desc='Destroy a spatial image tracking database handle',xrefs='xrCreateSpatialImageTrackingDatabaseAsyncEXT XrSpatialImageTrackingDatabaseEXT']
--
The flink:xrDestroySpatialImageTrackingDatabaseEXT function is defined as:

include::{generated}/api/protos/xrDestroySpatialImageTrackingDatabaseEXT.adoc[]

.Parameter Descriptions
****
* pname:database is an slink:XrSpatialImageTrackingDatabaseEXT previously
  created by flink:xrCreateSpatialImageTrackingDatabaseAsyncEXT.
****

The application can: call the flink:xrDestroySpatialImageTrackingDatabaseEXT
function to release the pname:database handle and the underlying resources
when finished with spatial image discovery and update tasks.

The application can: call the flink:xrDestroySpatialImageTrackingDatabaseEXT
function before calling flink:xrDestroySpatialContextEXT.
The runtime must: no longer report images managed by this destroyed
slink:XrSpatialImageTrackingDatabaseEXT.
The runtime must: continue to report images managed by other databases.

The runtime must: ensure that discovery snapshots returned by
flink:xrCreateSpatialDiscoverySnapshotCompleteEXT do not contain images
pertaining to destroyed or otherwise invalid
slink:XrSpatialImageTrackingDatabaseEXT handles, even if the handle was
destroyed after the application called
flink:xrCreateSpatialDiscoverySnapshotAsyncEXT.
Given that the data in a spatial snapshot is immutable, the application
should: destroy any slink:XrSpatialSnapshotEXT handles that were created
before it destroys pname:database, otherwise the application may: receive
invalid slink:XrSpatialImageTrackingDatabaseEXT handles when using
flink:xrQuerySpatialComponentDataEXT.

The application can: call the flink:xrDestroySpatialContextEXT function to
release the slink:XrSpatialContextEXT handle before destroying any of the
slink:XrSpatialImageTrackingDatabaseEXT handles that
slink:XrSpatialContextEXT was created with.
The runtime must: not implicitly destroy these
slink:XrSpatialImageTrackingDatabaseEXT handles when the
slink:XrSpatialContextEXT is destroyed.

Managing the lifetime of slink:XrSpatialContextEXT and
slink:XrSpatialImageTrackingDatabaseEXT independently enables applications
to reuse previously created slink:XrSpatialImageTrackingDatabaseEXT handles
without needing to re-perform the costly creation procedure.

For example, destroying an slink:XrSpatialContextEXT and subsequently
recreating another slink:XrSpatialContextEXT with the same
slink:XrSpatialImageTrackingDatabaseEXT enables pausing and resuming image
tracking without needing to perform another initialization procedure.

===== Static Image Optimization

[open,refpage='XrSpatialImageStaticOptimizationEXT',type='structs',desc='Provide information that images do not move.',xrefs='XrSpatialReferenceImageEXT XrSpatialImageTrackingDatabaseCreateInfoEXT']
--
The slink:XrSpatialImageStaticOptimizationEXT structure is defined as:

include::{generated}/api/structs/XrSpatialImageStaticOptimizationEXT.adoc[]

.Member Descriptions
****
* pname:type is the elink:XrStructureType of this structure.
* pname:next is code:NULL or a pointer to the next structure in a structure
  chain.
* pname:optimizeForStaticImage is an basetype:XrBool32 that indicates
  whether images move or not.
  A value of ename:XR_TRUE indicates that images do not move.
****

If ename:XR_SPATIAL_CAPABILITY_FEATURE_IMAGE_TRACKING_STATIC_IMAGES_EXT is
enumerated by flink:xrEnumerateSpatialCapabilityFeaturesEXT for the
ename:XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT capability, the application
can: chain slink:XrSpatialImageStaticOptimizationEXT to the
slink:XrSpatialImageTrackingDatabaseCreateInfoEXT::pname:next chain, or
slink:XrSpatialReferenceImageEXT::pname:next.

If the application chains slink:XrSpatialImageStaticOptimizationEXT to the
slink:XrSpatialImageTrackingDatabaseCreateInfoEXT structure, the runtime
must: assume that all images of that slink:XrSpatialImageTrackingDatabaseEXT
are static if pname:optimizeForStaticImage is set to ename:XR_TRUE.
Correspondingly, the runtime must: assume that all images of that
slink:XrSpatialImageTrackingDatabaseEXT are not static if
pname:optimizeForStaticImage is set to ename:XR_FALSE.

If application chains slink:XrSpatialImageStaticOptimizationEXT to the
slink:XrSpatialReferenceImageEXT structure, the runtime must: assume that
this reference image is static if pname:optimizeForStaticImage is set to
ename:XR_TRUE.
Correspondingly, the runtime must: assume that this reference image is not
static if pname:optimizeForStaticImage is set to ename:XR_FALSE.
Chaining the slink:XrSpatialImageStaticOptimizationEXT structure to the
slink:XrSpatialReferenceImageEXT structure takes precedence over chaining it
to the slink:XrSpatialImageTrackingDatabaseCreateInfoEXT structure.

If ename:XR_SPATIAL_CAPABILITY_FEATURE_IMAGE_TRACKING_STATIC_IMAGES_EXT is
not enumerated by flink:xrEnumerateSpatialCapabilityFeaturesEXT for the
ename:XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT capability and the
application chains an slink:XrSpatialImageStaticOptimizationEXT structure to
any of the applicable next chains the runtime must: return
ename:XR_ERROR_VALIDATION_FAILURE from
flink:xrCreateSpatialImageTrackingDatabaseAsyncEXT.

This may: allow the runtime to generate a more accurate pose and size.

This may: allow the runtime to reduce power consumption.

==== Guaranteed Components

A runtime that supports ename:XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT must:
provide the following spatial components as guaranteed components of all
entities discovered by those capabilities, and must: enumerate them in

* ename:XR_SPATIAL_COMPONENT_TYPE_IMAGE_2D_EXT
* ename:XR_SPATIAL_COMPONENT_TYPE_BOUNDED_2D_EXT

====== Configuration

If ename:XR_SPATIAL_COMPONENT_TYPE_IMAGE_2D_EXT is enumerated in
slink:XrSpatialCapabilityComponentTypesEXT::pname:componentTypes for some
capability, the application can: enable it by including the enum value in
the
slink:XrSpatialCapabilityConfigurationBaseHeaderEXT::pname:enabledComponents
list.
This component does not require any special configuration to be included in
the next chain of slink:XrSpatialCapabilityConfigurationBaseHeaderEXT.

===== Bounded 2D Component

The bounded 2D component provides the center and extents of the spatial
image represented by the entity it is on.
See <<ext_spatial_entity_bounded2D_component>> for more details about the
bounded 2D component.

==== Example Code

===== Discover Spatial Images & Query Component Data

The following example code demonstrates how to discover spatial entities for
the image tracking capability and query its component data.

[source,cpp]
----
XrInstance instance; // Previously initialized
XrSystemId systemId; // Previously initialized
XrSession session; // Previously initialized
XrSpace localSpace; // Previously initialized

uint32_t capabilityCountOutput = 0;
CHK_XR(xrEnumerateSpatialCapabilitiesEXT(instance, systemId, 0, &capabilityCountOutput, nullptr));
std::vector<XrSpatialCapabilityEXT> capabilities(capabilityCountOutput);
CHK_XR(xrEnumerateSpatialCapabilitiesEXT(instance, systemId, capabilities.size(), &capabilityCountOutput, capabilities.data()));

if (std::find(capabilities.begin(), capabilities.end(), XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT) == capabilities.end()) {
  // Image tracking not supported
}

XrSpatialCapabilityComponentTypesEXT imageTrackingComponents{
  .type = XR_TYPE_SPATIAL_CAPABILITY_COMPONENT_TYPES_EXT,
};
CHK_XR(xrEnumerateSpatialCapabilityComponentTypesEXT(instance, systemId, XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT, &imageTrackingComponents));
std::vector<XrSpatialComponentTypeEXT> imageTrackingCapabilityComponents(imageTrackingComponents.componentTypeCountOutput);
imageTrackingComponents.componentTypes = imageTrackingCapabilityComponents.data();
CHK_XR(xrEnumerateSpatialCapabilityComponentTypesEXT(instance, systemId, XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT, &imageTrackingComponents));

if (std::find(imageTrackingCapabilityComponents.begin(), imageTrackingCapabilityComponents.end(), XR_SPATIAL_COMPONENT_TYPE_IMAGE_2D_EXT) == imageTrackingCapabilityComponents.end()) {
  // The image2d component is not supported
}

uint32_t capabilityFeatureCountOutput = 0;
CHK_XR(xrEnumerateSpatialCapabilityFeaturesEXT(instance, systemId, XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT, 0, &capabilityFeatureCountOutput, nullptr));
std::vector<XrSpatialCapabilityFeatureEXT> capabilityFeatures(capabilityFeatureCountOutput);
CHK_XR(xrEnumerateSpatialCapabilityFeaturesEXT(instance, systemId, XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT, capabilityFeatures.size(), &capabilityFeatureCountOutput, capabilityFeatures.data()));

// Helper function to query optional feature support
const auto supportsFeature = [&capabilityFeatures](XrSpatialCapabilityFeatureEXT feature) {
  return std::find(capabilityFeatures.begin(), capabilityFeatures.end(), feature) != capabilityFeatures.end();
};

// supported state for optional features
const bool supportsAutomaticScaleEstimation = supportsFeature(XR_SPATIAL_CAPABILITY_FEATURE_IMAGE_TRACKING_AUTOMATIC_SIZE_IMAGES_EXT);
const bool supportsStaticImages = supportsFeature(XR_SPATIAL_CAPABILITY_FEATURE_IMAGE_TRACKING_STATIC_IMAGES_EXT);
const bool supportsFixedSizeImages = supportsFeature(XR_SPATIAL_CAPABILITY_FEATURE_IMAGE_TRACKING_FIXED_SIZE_IMAGES_EXT);

uint32_t formatCountOutput = 0;
CHK_XR(xrEnumerateSpatialReferenceImageFormatsEXT(instance, systemId, XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT, 0, &formatCountOutput, nullptr));
std::vector<XrSpatialReferenceImageFormatEXT> formats(formatCountOutput);
CHK_XR(xrEnumerateSpatialReferenceImageFormatsEXT(instance, systemId, XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT, formats.size(), &formatCountOutput, formats.data()));

if (std::find(formats.begin(), formats.end(), XR_SPATIAL_REFERENCE_IMAGE_FORMAT_RGBA_8888_EXT) == formats.end()) {
  // The desired format is not supported
}

// Helper function to wait for XrFutureEXT completion
auto waitUntilReady = [&](XrFutureEXT future) {
  XrFuturePollInfoEXT pollInfo{
    .type = XR_TYPE_FUTURE_POLL_INFO_EXT,
    .future = future,
  };
  XrFuturePollResultEXT pollResult{
    .type = XR_TYPE_FUTURE_POLL_RESULT_EXT,
  };
  do {
    // sleep(1);
    CHK_XR(xrPollFutureEXT(instance, &pollInfo, &pollResult));
  } while (pollResult.state != XR_FUTURE_STATE_READY_EXT);
};

// Data/metadata about reference images (identifiers, 3D models, trigger functions, etc.)
std::vector<std::string> referenceImageIdentifiers;

XrSpatialImageTrackingDatabaseEXT imageTrackingDatabase{};
{
  uint32_t imgSize; // preloaded interleaved RGBA buffer size
  uint8_t* img; // preloaded interleaved RGBA buffer data

  // interleaved RGBA buffer memory layout and buffer positions

  // first row of pixels
  // img[0] | img[1] | img[2] | img[3] | img[0]+pStride | img[1]+pStride | ...
  //  R0    |   G0   |   B0   |   A0   |       R1       |       G1       | ...

  // second row of pixels
  // img[0]+rStride | img[1]+rStride | img[2]+rStride | img[3]+rStride | img[0]+rStride+pStride | ...
  //      R640      |      G640      |      B640      |      A640      |          R641          | ...

  XrSpatialReferenceImagePlaneEXT spatialReferenceImagePlanes[4];

  for (int i = 0; i < 4; ++i) { // for each plane (0=R, 1=G, 2=B, 3=A)
    spatialReferenceImagePlanes[i].buffer = img + i; // set each plane buffer pointer to this channel's byte in the first pixel
    spatialReferenceImagePlanes[i].bufferSize = imgSize - i; // adjust remaining buffer size according to offset applied
    spatialReferenceImagePlanes[i].rowStride = 640 * 4; // set byte offset to start of next row for this plane
    spatialReferenceImagePlanes[i].pixelStride = 4; // set byte offset to next pixel for this plane
  }

  XrSpatialReferenceImageEXT spatialReferenceImage{
    .type = XR_TYPE_SPATIAL_REFERENCE_IMAGE_EXT,
    .width = 640,
    .height = 480,
    .format = XR_SPATIAL_REFERENCE_IMAGE_FORMAT_RGBA_8888_EXT,
    .planeCount = 4,
    .planes = spatialReferenceImagePlanes,
  };

  referenceImageIdentifiers.emplace_back("MyReferenceImage");

  // Helper function to append to the next chain
  XrBaseOutStructure* appendTo = reinterpret_cast<XrBaseOutStructure*>(&spatialReferenceImage);
  const auto appendToNextChain = [&appendTo](XrBaseOutStructure* toAppend) {
    appendTo->next = toAppend;
    appendTo = toAppend;
  };

  XrSpatialImageSizeEXT imageSize {
    .type = XR_TYPE_SPATIAL_IMAGE_SIZE_EXT,
    .physicalWidth = 0.1f,
  };

  if (!supportsAutomaticScaleEstimation) {
    if (supportsFixedSizeImages) {
      appendToNextChain(reinterpret_cast<XrBaseOutStructure*>(&imageSize));
    }
  }

  XrSpatialImageStaticOptimizationEXT imageStaticOptimization{
    .type = XR_TYPE_SPATIAL_IMAGE_STATIC_OPTIMIZATION_EXT,
    .optimizeForStaticImage = XR_TRUE,
  };

  if (supportsStaticImages) {
    appendToNextChain(reinterpret_cast<XrBaseOutStructure*>(&imageStaticOptimization));
  }

  XrSpatialImageTrackingDatabaseCreateInfoEXT spatialImageTrackingDatabaseCreateInfo {
    .type = XR_TYPE_SPATIAL_IMAGE_TRACKING_DATABASE_CREATE_INFO_EXT,
    .spatialReferenceImageCount = 1,
    .spatialReferenceImages = &spatialReferenceImage,
  };

  XrFutureEXT createImageTrackingDatabaseFuture {XR_NULL_FUTURE_EXT};
  CHK_XR(xrCreateSpatialImageTrackingDatabaseAsyncEXT(session, &spatialImageTrackingDatabaseCreateInfo, &createImageTrackingDatabaseFuture));

  waitUntilReady(createImageTrackingDatabaseFuture);

  XrCreateSpatialImageTrackingDatabaseCompletionEXT imageTrackingCompletion{
    .type = XR_TYPE_CREATE_SPATIAL_IMAGE_TRACKING_DATABASE_COMPLETION_EXT,
  };
  CHK_XR(xrCreateSpatialImageTrackingDatabaseCompleteEXT(session, createImageTrackingDatabaseFuture, &imageTrackingCompletion));
  if (imageTrackingCompletion.futureResult != XR_SUCCESS) {
    // Error, image tracking database creation failed
  }

  imageTrackingDatabase = imageTrackingCompletion.database;
}

XrSpatialContextEXT spatialContext{};
{
  const std::array<XrSpatialComponentTypeEXT, 2> enabledComponents = {
    XR_SPATIAL_COMPONENT_TYPE_BOUNDED_2D_EXT,
    XR_SPATIAL_COMPONENT_TYPE_IMAGE_2D_EXT
  };

  // Configure the image tracking capability for the spatial context
  XrSpatialCapabilityConfigurationImageTrackingEXT imageTrackingCapabilityConfig{
    .type = XR_TYPE_SPATIAL_CAPABILITY_CONFIGURATION_IMAGE_TRACKING_EXT,
    .capability = XR_SPATIAL_CAPABILITY_IMAGE_TRACKING_EXT,
    .enabledComponentCount = enabledComponents.size(),
    .enabledComponents = enabledComponents.data(),
    .imageTrackingDatabaseCount = 1,
    .imageTrackingDatabases = &imageTrackingDatabase,
  };

  std::vector<XrSpatialCapabilityConfigurationBaseHeaderEXT*> capabilityConfigs;
  capabilityConfigs.push_back(reinterpret_cast<XrSpatialCapabilityConfigurationBaseHeaderEXT*>(&imageTrackingCapabilityConfig));

  XrSpatialContextCreateInfoEXT spatialContextCreateInfo{
    .type = XR_TYPE_SPATIAL_CONTEXT_CREATE_INFO_EXT,
    .capabilityConfigCount = static_cast<uint32_t>(capabilityConfigs.size()),
    .capabilityConfigs = capabilityConfigs.data(),
  };

  XrFutureEXT createContextFuture {XR_NULL_FUTURE_EXT};
  CHK_XR(xrCreateSpatialContextAsyncEXT(session, &spatialContextCreateInfo, &createContextFuture));

  waitUntilReady(createContextFuture);

  XrCreateSpatialContextCompletionEXT completion{
    .type = XR_TYPE_CREATE_SPATIAL_CONTEXT_COMPLETION_EXT,
  };
  CHK_XR(xrCreateSpatialContextCompleteEXT(session, createContextFuture, &completion));
  if (completion.futureResult != XR_SUCCESS) {
    // Error, spatial context creation failed
  }

  spatialContext = completion.spatialContext;
}

// Track entity handles for per-frame updates
std::vector<XrSpatialEntityEXT> entityHandles;

auto discoverSpatialEntities = [&](XrSpatialContextEXT spatialContext, XrTime time) {
  // We want to look for entities that have the following components
  std::array<XrSpatialComponentTypeEXT, 2> snapshotComponents {XR_SPATIAL_COMPONENT_TYPE_BOUNDED_2D_EXT, XR_SPATIAL_COMPONENT_TYPE_IMAGE_2D_EXT};

  XrSpatialDiscoverySnapshotCreateInfoEXT snapshotCreateInfo{
    .type = XR_TYPE_SPATIAL_DISCOVERY_SNAPSHOT_CREATE_INFO_EXT,
    .componentTypeCount = snapshotComponents.size(),
    .componentTypes = snapshotComponents.data(),
  };
  XrFutureEXT discoveryFuture {XR_NULL_FUTURE_EXT};
  CHK_XR(xrCreateSpatialDiscoverySnapshotAsyncEXT(spatialContext, &snapshotCreateInfo, &discoveryFuture));

  waitUntilReady(discoveryFuture);

  XrCreateSpatialDiscoverySnapshotCompletionInfoEXT completionInfo{
    .type = XR_TYPE_CREATE_SPATIAL_DISCOVERY_SNAPSHOT_COMPLETION_INFO_EXT,
    .baseSpace = localSpace,
    .time = time,
    .future = discoveryFuture,
  };

  XrCreateSpatialDiscoverySnapshotCompletionEXT completion{
    .type = XR_TYPE_CREATE_SPATIAL_DISCOVERY_SNAPSHOT_COMPLETION_EXT,
  };
  CHK_XR(xrCreateSpatialDiscoverySnapshotCompleteEXT(spatialContext, &completionInfo, &completion));
  if (completion.futureResult == XR_SUCCESS) {
    // Query for the bounded2d component data
    XrSpatialComponentTypeEXT componentsToQuery[] = {XR_SPATIAL_COMPONENT_TYPE_BOUNDED_2D_EXT, XR_SPATIAL_COMPONENT_TYPE_IMAGE_2D_EXT};
    XrSpatialComponentDataQueryConditionEXT queryCond{
      .type = XR_TYPE_SPATIAL_COMPONENT_DATA_QUERY_CONDITION_EXT,
      .componentTypeCount = 2,
      .componentTypes = componentsToQuery,
    };

    XrSpatialComponentDataQueryResultEXT queryResult{
      .type = XR_TYPE_SPATIAL_COMPONENT_DATA_QUERY_RESULT_EXT,
    };
    CHK_XR(xrQuerySpatialComponentDataEXT(completion.snapshot, &queryCond, &queryResult));

    std::vector<XrSpatialEntityIdEXT> discoveredEntityIds(queryResult.entityIdCountOutput);
    std::vector<XrSpatialEntityTrackingStateEXT> entityStates(queryResult.entityStateCountOutput);
    queryResult.entityIdCapacityInput = discoveredEntityIds.size();
    queryResult.entityIds = discoveredEntityIds.data();
    queryResult.entityStateCapacityInput = entityStates.size();
    queryResult.entityStates = entityStates.data();

    std::vector<XrSpatialBounded2DDataEXT> bounded2d(queryResult.entityIdCountOutput);
    std::vector<XrSpatialImage2DDataEXT> image2d(queryResult.entityIdCountOutput);

    XrSpatialComponentImage2DListEXT imagesList{
      .type = XR_TYPE_SPATIAL_COMPONENT_IMAGE_2D_LIST_EXT,
      .imageCount = static_cast<uint32_t>(image2d.size()),
      .images = image2d.data(),
    };

    XrSpatialComponentBounded2DListEXT boundsList{
      .type = XR_TYPE_SPATIAL_COMPONENT_BOUNDED_2D_LIST_EXT,
      .boundCount = static_cast<uint32_t>(bounded2d.size()),
      .bounds = bounded2d.data(),
    };

    imagesList.next = &boundsList;
    queryResult.next = &imagesList;

    CHK_XR(xrQuerySpatialComponentDataEXT(completion.snapshot, &queryCond, &queryResult));

    // Create entity handles for newly discovered entities
    for (int32_t i = 0; i < queryResult.entityIdCountOutput; ++i) {
      if (entityStates[i] == XR_SPATIAL_ENTITY_TRACKING_STATE_TRACKING_EXT) {
        const XrSpatialImage2DDataEXT& currentImage2d = image2d[i];
        const std::string& currentReferenceImageIdentifier = referenceImageIdentifiers[currentImage2d.referenceImageIndex];
        std::cout << currentReferenceImageIdentifier << std::endl; // Outputs the "MyReferenceImage" string the app defined previously; could be any other associated data or action.

        // Access bounded2d[i] for image bounds

        // Create entity handle for this entity
        XrSpatialEntityFromIdCreateInfoEXT createInfo{
          .type = XR_TYPE_SPATIAL_ENTITY_FROM_ID_CREATE_INFO_EXT,
          .entityId = discoveredEntityIds[i],
        };
        XrSpatialEntityEXT handle {XR_NULL_HANDLE};
        CHK_XR(xrCreateSpatialEntityFromIdEXT(spatialContext, &createInfo, &handle));
        entityHandles.push_back(handle);
      }
    }

    CHK_XR(xrDestroySpatialSnapshotEXT(completion.snapshot));
  }
};

while (1) {
  // For every frame in frame loop

  XrFrameState frameState;  // Previously returned from xrWaitFrame
  const XrTime time = frameState.predictedDisplayTime;

  // Poll for the XR_TYPE_EVENT_DATA_SPATIAL_DISCOVERY_RECOMMENDED_EXT event
  XrEventDataBuffer event {
    .type = XR_TYPE_EVENT_DATA_BUFFER,
  };
  XrResult result = xrPollEvent(instance, &event);
  if (result == XR_SUCCESS) {
    switch (event.type) {
      case XR_TYPE_EVENT_DATA_SPATIAL_DISCOVERY_RECOMMENDED_EXT: {
        const XrEventDataSpatialDiscoveryRecommendedEXT& eventdata = *reinterpret_cast<XrEventDataSpatialDiscoveryRecommendedEXT*>(&event);
        // Discover spatial entities for the context that we received the "discovery
        // recommended" event for
        discoverSpatialEntities(eventdata.spatialContext, time);
        break;
      }
    }
  }

  // Update existing entities every frame
  if (!entityHandles.empty()) {
    std::array<XrSpatialComponentTypeEXT, 2> componentsToUpdate = {
      XR_SPATIAL_COMPONENT_TYPE_BOUNDED_2D_EXT,
      XR_SPATIAL_COMPONENT_TYPE_IMAGE_2D_EXT
    };

    XrSpatialUpdateSnapshotCreateInfoEXT updateSnapshotCreateInfo {
      .type = XR_TYPE_SPATIAL_UPDATE_SNAPSHOT_CREATE_INFO_EXT,
      .entityCount = static_cast<uint32_t>(entityHandles.size()),
      .entities = entityHandles.data(),
      .componentTypeCount = static_cast<uint32_t>(componentsToUpdate.size()),
      .componentTypes = componentsToUpdate.data(),
      .baseSpace = localSpace,
      .time = time,
    };

    XrSpatialSnapshotEXT updateSnapshot {XR_NULL_HANDLE};
    CHK_XR(xrCreateSpatialUpdateSnapshotEXT(spatialContext, &updateSnapshotCreateInfo, &updateSnapshot));

    // Query updated component data (same pattern as discovery)
    XrSpatialComponentDataQueryConditionEXT queryCond{
      .type = XR_TYPE_SPATIAL_COMPONENT_DATA_QUERY_CONDITION_EXT,
      .componentTypeCount = static_cast<uint32_t>(componentsToUpdate.size()),
      .componentTypes = componentsToUpdate.data(),
    };

    XrSpatialComponentDataQueryResultEXT queryResult{
      .type = XR_TYPE_SPATIAL_COMPONENT_DATA_QUERY_RESULT_EXT,
    };

    std::vector<XrSpatialEntityIdEXT> updatedEntityIds(entityHandles.size());
    std::vector<XrSpatialEntityTrackingStateEXT> entityStates(entityHandles.size());
    queryResult.entityIdCapacityInput = updatedEntityIds.size();
    queryResult.entityIds = updatedEntityIds.data();
    queryResult.entityStateCapacityInput = entityStates.size();
    queryResult.entityStates = entityStates.data();

    std::vector<XrSpatialBounded2DDataEXT> bounded2d(entityHandles.size());
    std::vector<XrSpatialImage2DDataEXT> image2d(entityHandles.size());

    XrSpatialComponentImage2DListEXT imagesList{
      .type = XR_TYPE_SPATIAL_COMPONENT_IMAGE_2D_LIST_EXT,
      .imageCount = static_cast<uint32_t>(image2d.size()),
      .images = image2d.data(),
    };

    XrSpatialComponentBounded2DListEXT boundsList{
      .type = XR_TYPE_SPATIAL_COMPONENT_BOUNDED_2D_LIST_EXT,
      .boundCount = static_cast<uint32_t>(bounded2d.size()),
      .bounds = bounded2d.data(),
    };

    imagesList.next = &boundsList;
    queryResult.next = &imagesList;

    CHK_XR(xrQuerySpatialComponentDataEXT(updateSnapshot, &queryCond, &queryResult));
    CHK_XR(xrDestroySpatialSnapshotEXT(updateSnapshot));
  }

  // Finish frame loop
}

// Clean up entity handles when no longer needed
for (auto handle : entityHandles) {
  CHK_XR(xrDestroySpatialEntityEXT(handle));
}

CHK_XR(xrDestroySpatialContextEXT(spatialContext));

// Unload spatial image tracking resources internally
CHK_XR(xrDestroySpatialImageTrackingDatabaseEXT(imageTrackingDatabase));
