==== Overview

This extension enables applications to acquire image data from cameras on XR
devices.
It depends on the apiext:XR_EXT_future extension, which must: be enabled to
use this extension.

Key terms defined in this extension:

* **Camera**: A device (physical or virtual) that provides image data.
* **Camera Property**: Attributes of a camera that help developers identify
  it, such as orientation, position, and type.
* **Camera Capability**: Configurable features supported by a camera,
  including resolution, frame rate, image format, and data transfer method.
* **Camera Capture Session**: A configured stream associated with a camera.
  Applications retrieve camera images from a capture session.
  A camera may: support multiple capture sessions, subject to
  runtime-imposed limits.
* **Camera Image**: Captured image data obtained from a Camera Capture
  Session.

The typical workflow for using this extension is as follows:

1. Enumerate available cameras, optionally applying filters.
2. Retrieve camera properties or capabilities (if needed) to select a
   suitable camera.
3. Create a Camera Device handle.
4. Create a Camera Capture Session with specific configurations.
5. Begin the capture session to request the runtime to update camera images.
6. Acquire camera images and retrieve their data, optionally with the
   intrinsics and extrinsics.
7. Release camera images when no longer needed.
8. End and destroy the capture session when image capture is complete.
9. Destroy the Camera Device handle.

==== Permissions

If a runtime enforces a permission system to control application access to
camera data, and if the application has not been granted permission,
flink:xrCreateCameraDeviceAsyncBD must: return
ename:XR_ERROR_PERMISSION_INSUFFICIENT.

On AOSP-based systems, the runtime must: enforce the use of the
`android.permission.CAMERA` permission string for this functionality.


Since flink:xrCreateCameraDeviceAsyncBD may: return a permission error,
applications should: use platform APIs to check and request the appropriate
permissions before creating a camera device.


On AOSP-based platforms, if the user revokes permission after the handle is
created, the runtime may: terminate the application's process.


==== Camera Representations
===== Camera ID
[open,refpage='XrCameraIdBD',type='basetypes',desc='ID referring to a camera']
--
include::{generated}/api/basetypes/XrCameraIdBD.adoc[]

basetype:XrCameraIdBD is an opaque atom used to identify a physical or
virtual camera supported by the runtime.
A valid basetype:XrCameraIdBD is tied to an slink:XrInstance, and the
runtime must: not reuse the same ID for different cameras within the same
slink:XrInstance.
--

===== Camera Device Handle
[open,refpage='XrCameraDeviceBD',type='handles',desc='Represents a camera device']
--

The slink:XrCameraDeviceBD handle represents a logical connection to a
camera.
Applications create this handle to express intent to access a specific
camera and retrieve its images.
The runtime may: initialize the physical/virtual camera when this handle is
created.
--

.Parameter Descriptions
****
* pname:instance is a handle to an slink:XrInstance.
* pname:enumerateInfo is an slink:XrAvailableCamerasEnumerateInfoBD
  structure containing filter criteria.
* pname:cameraCapacityInput is the capacity of the pname:cameras array, or 0
  to indicate a request to retrieve the required capacity.

code:NULL, the runtime must: return cameras that match **all** properties or
capabilities.
If properties and capabilities are both not code:NULL, the runtime must: use
an 'AND' operator for properties and capabilities filters, which means
return cameras that match **all** properties and capabilities.

If slink:XrAvailableCamerasEnumerateInfoBD::pname:properties or
slink:XrAvailableCamerasEnumerateInfoBD::pname:capabilities is code:NULL,
the corresponding filter is not applied.

The runtime must: keep the number of enumerated cameras for given filters
constant over the lifetime of the current instance.

.Parameter Descriptions

* pname:captureSession is a handle to an slink:XrCameraCaptureSessionBD.
* pname:imageId is the basetype:XrCameraImageIdBD of the image to release.

Applications should: call this function to release resources for an acquired

Destroying the associated slink:XrCameraCaptureSessionBD must: implicitly

to acquire that same image again.

If the runtime allows acquiring more than one image, it must: allow
releasing them in an order different than the acquire order.

// Enumerate available cameras with property filter and capability filter

XrCameraPropertyFacingBD facingFilter {
  .type = XR_TYPE_CAMERA_PROPERTY_FACING_BD,
  .facing = XR_CAMERA_FACING_WORLD_BD,
};

XrCameraPropertyPositionBD positionFilter {
  .type = XR_TYPE_CAMERA_PROPERTY_POSITION_BD,
  .position = XR_CAMERA_POSITION_LEFT_BD,
};

std::vector<XrCameraPropertyBaseHeaderBD*> propertyFilters{
    (XrCameraPropertyBaseHeaderBD *)&facingFilter,
    (XrCameraPropertyBaseHeaderBD *)&positionFilter
};

XrCameraPropertiesBD filterProperties {
  .type = XR_TYPE_CAMERA_PROPERTIES_BD,
  .propertyCount = static_cast<uint32_t>(propertyFilters.size()),
  .properties = propertyFilters.data(),
};

XrCameraCapabilityDataTransferTypeBD transferTypeFilter {
  .type = XR_TYPE_CAMERA_CAPABILITY_DATA_TRANSFER_TYPE_BD,
  .transferType = XR_CAMERA_DATA_TRANSFER_TYPE_RAW_BUFFER_BD,
};

XrCameraCapabilityImageFormatBD imageFormatFilter {
  .type = XR_TYPE_CAMERA_CAPABILITY_IMAGE_FORMAT_BD,
  .format = XR_CAMERA_IMAGE_FORMAT_RGBA_8888_BD,
};

XrCameraCapabilityCameraModelBD cameraModelFilter {
  .type = XR_TYPE_CAMERA_CAPABILITY_CAMERA_MODEL_BD,
  .model = XR_CAMERA_MODEL_PINHOLE_BD,
};

std::vector<XrCameraCapabilityBaseHeaderBD*> capabilityFilters{
    (XrCameraCapabilityBaseHeaderBD *)&transferTypeFilter,
    (XrCameraCapabilityBaseHeaderBD *)&imageFormatFilter,
    (XrCameraCapabilityBaseHeaderBD *)&cameraModelFilter,
};

XrCameraCapabilitiesBD filterCapabilities {
  .type = XR_TYPE_CAMERA_CAPABILITIES_BD,
  .capabilityCount = static_cast<uint32_t>(capabilityFilters.size()),
  .capabilities = capabilityFilters.data(),
};

XrAvailableCamerasEnumerateInfoBD enumerateInfo {
  .type = XR_TYPE_AVAILABLE_CAMERAS_ENUMERATE_INFO_BD,
  .properties = &filterProperties,
  .capabilities = &filterCapabilities,
};

uint32_t cameraCount;
xrEnumerateAvailableCamerasBD(instance, &enumerateInfo, 0, &cameraCount, NULL);

std::vector<XrAvailableCameraBD> cameras(cameraCount);

xrEnumerateAvailableCamerasBD(instance, &enumerateInfo, cameraCount, &cameraCount, cameras.data());
if (cameraCount == 0)
{
    // Handle no camera available
}

// Get the 1st camera
XrCameraIdBD targetCameraId = cameras[0].cameraId;

// Create camera device
XrCameraDeviceCreateInfoBD createDeviceInfo {
  .type = XR_TYPE_CAMERA_DEVICE_CREATE_INFO_BD,
  .cameraId = targetCameraId,
};
XrFutureEXT createDeviceFuture {XR_NULL_FUTURE_EXT};
XrResult result = xrCreateCameraDeviceAsyncBD(instance, &createDeviceInfo, &createDeviceFuture);
if (result != XR_SUCCESS)
{
    // Handle creation error
}

// Wait for device creation to complete
waitUntilReady(createDeviceFuture);

XrCreateCameraDeviceCompletionBD deviceCompletion {
  .type = XR_TYPE_CREATE_CAMERA_DEVICE_COMPLETION_BD,
};
result = xrCreateCameraDeviceCompleteBD(instance, createDeviceFuture, &deviceCompletion);
if (deviceCompletion.futureResult != XR_SUCCESS)
{
    // Handle async failure
}
XrCameraDeviceBD cameraDevice = deviceCompletion.device;

// Check supported capability types
XrCameraCapabilityTypesEnumerateInfoBD capabilityTypesEnumerateInfo {
  .type = XR_TYPE_CAMERA_CAPABILITY_TYPES_ENUMERATE_INFO_BD,
  .cameraId = targetCameraId,
};

XrCameraCapabilityTypesBD capabilityTypes {
  .type = XR_TYPE_CAMERA_CAPABILITY_TYPES_BD,
  .capabilityTypeCapacityInput = 0,
};

// First call to get capability type count
result = xrEnumerateCameraCapabilityTypesBD(instance, &capabilityTypesEnumerateInfo, &capabilityTypes);

if (result != XR_SUCCESS)
{
    // Handle enumeration error
}

if (capabilityTypes.capabilityTypeCountOutput == 0)
{
    // Handle no type count
}

// Second call to get the capability types
std::vector<XrCameraCapabilityTypeBD> capabilityTypesArray(capabilityTypes.capabilityTypeCountOutput);
capabilityTypes.capabilityTypeCapacityInput = capabilityTypes.capabilityTypeCountOutput;
capabilityTypes.capabilityTypes = capabilityTypesArray.data();

result = xrEnumerateCameraCapabilityTypesBD(instance, &capabilityTypesEnumerateInfo, &capabilityTypes);
if (result != XR_SUCCESS)
{
    // Handle enumeration error
}

// Assume the XR_CAMERA_CAPABILITY_TYPE_IMAGE_RESOLUTION_AND_FRAME_RATE_BD is in the returned capabilityTypes

// Get capability values.
XrCameraSupportedCapabilityImageResolutionAndFrameRateBD supportedResAndFrameRate {
  .type = XR_TYPE_CAMERA_SUPPORTED_CAPABILITY_IMAGE_RESOLUTION_AND_FRAME_RATE_BD,
  .resolutionAndFrameRateCapacityInput = 0,
  .resolutionAndFrameRateCountOutput = 0,
  .resolutionAndFrameRates = nullptr,
};

XrCameraSupportedCapabilitiesGetInfoBD capabilityGetInfo {
  .type = XR_TYPE_CAMERA_SUPPORTED_CAPABILITIES_GET_INFO_BD,
  .id = targetCameraId,
};

std::vector<XrCameraSupportedCapabilityBaseHeaderBD*> supportedCapabilityValues{
    (XrCameraSupportedCapabilityBaseHeaderBD *)&supportedResAndFrameRate
};

XrCameraSupportedCapabilitiesBD supportedCapabilities {
  .type = XR_TYPE_CAMERA_SUPPORTED_CAPABILITIES_BD,
  .capabilityCount = static_cast<uint32_t>(supportedCapabilityValues.size()),
  .capabilities = supportedCapabilityValues.data(),
};

// First call to get supported value count
result = xrGetCameraSupportedCapabilitiesBD(instance, &capabilityGetInfo, &supportedCapabilities);
if (result != XR_SUCCESS)
{
    // Handle get error
}

if (supportedResAndFrameRate.resolutionAndFrameRateCountOutput == 0)
{
    // Handle no count error
}

uint32_t count = supportedResAndFrameRate.resolutionAndFrameRateCountOutput;

std::vector<XrCameraImageResolutionAndFrameRateBD> resAndFrameRates(count);

supportedResAndFrameRate.resolutionAndFrameRateCapacityInput = count;
supportedResAndFrameRate.resolutionAndFrameRates = resAndFrameRates.data();

result = xrGetCameraSupportedCapabilitiesBD(instance, &capabilityGetInfo, &supportedCapabilities);
if (result != XR_SUCCESS)

    // Handle get error
}

// Configure capture session (1024x768, 30 frame rate, raw buffer transfer, RGBA8888, pinhole model)
XrCameraCapabilityImageResolutionAndFrameRateBD resAndFrameRateConfig {
  .type = XR_TYPE_CAMERA_CAPABILITY_IMAGE_RESOLUTION_AND_FRAME_RATE_BD,
  .resolution = {
    .width = 1024,
    .height = 768,
  },
  .frameRate = 30,
};

XrCameraCapabilityDataTransferTypeBD transferConfig {
  .type = XR_TYPE_CAMERA_CAPABILITY_DATA_TRANSFER_TYPE_BD,
  .transferType = XR_CAMERA_DATA_TRANSFER_TYPE_RAW_BUFFER_BD,
};

XrCameraCapabilityImageFormatBD formatConfig {
  .type = XR_TYPE_CAMERA_CAPABILITY_IMAGE_FORMAT_BD,
  .format = XR_CAMERA_IMAGE_FORMAT_RGBA_8888_BD,
};

XrCameraCapabilityCameraModelBD modelConfig {
  .type = XR_TYPE_CAMERA_CAPABILITY_CAMERA_MODEL_BD,
  .model = XR_CAMERA_MODEL_PINHOLE_BD,
};

std::vector<XrCameraCapabilityBaseHeaderBD*> sessionConfigs{
    (XrCameraCapabilityBaseHeaderBD *)&resAndFrameRateConfig,
    (XrCameraCapabilityBaseHeaderBD *)&transferConfig,
    (XrCameraCapabilityBaseHeaderBD *)&formatConfig,
    (XrCameraCapabilityBaseHeaderBD *)&modelConfig,
};

// Create capture session (async)
XrCameraCaptureSessionCreateInfoBD createSessionInfo {
  .type = XR_TYPE_CAMERA_CAPTURE_SESSION_CREATE_INFO_BD,
  .camera = cameraDevice,
  .configCount = static_cast<uint32_t>(sessionConfigs.size()),
  .configs = sessionConfigs.data(),
};
XrFutureEXT createSessionFuture {XR_NULL_FUTURE_EXT};
result = xrCreateCameraCaptureSessionAsyncBD(session, &createSessionInfo, &createSessionFuture);
if (result != XR_SUCCESS)
{
    // Handle session creation error
}

// Wait for session creation to complete
waitUntilReady(createSessionFuture);

XrCreateCameraCaptureSessionCompletionBD sessionCompletion {
  .type = XR_TYPE_CREATE_CAMERA_CAPTURE_SESSION_COMPLETION_BD,
};
result = xrCreateCameraCaptureSessionCompleteBD(session, createSessionFuture, &sessionCompletion);
if (sessionCompletion.futureResult != XR_SUCCESS)
{
    // Handle async failure
}
XrCameraCaptureSessionBD captureSession = sessionCompletion.captureSession;

// Begin capture
XrCameraCaptureBeginInfoBD beginInfo {
  .type = XR_TYPE_CAMERA_CAPTURE_BEGIN_INFO_BD,
};
result = xrBeginCameraCaptureBD(captureSession, &beginInfo);
if (result != XR_SUCCESS)
{
    // Handle begin error
}

// Acquire and process images
XrTime lastCaptureTime = 0;

XrCameraImageAcquireInfoBD acquireInfo {
  .type = XR_TYPE_CAMERA_IMAGE_ACQUIRE_INFO_BD,
  .lastCaptureTime = lastCaptureTime,
};

XrCameraImageBD image {
  .type = XR_TYPE_CAMERA_IMAGE_BD,
};
result = xrAcquireCameraImageBD(captureSession, &acquireInfo, &image);
if (result != XR_SUCCESS)
{
    // Handle acquisition error
}
else if (image.available == XR_FALSE)
{
    // No new image yet;
}
else // New image available
{
    // Get image data (raw buffer), intrinsics and extrinsics
    XrCameraExtrinsicsBD extrinsics {
      .type = XR_TYPE_CAMERA_EXTRINSICS_BD,
    };
    XrCameraIntrinsicsBD intrinsics {
      .type = XR_TYPE_CAMERA_INTRINSICS_BD,
      .next = &extrinsics,
    };
    XrCameraImageDataRawBufferBD imageData {
      .type = XR_TYPE_CAMERA_IMAGE_DATA_RAW_BUFFER_BD,
      .next = &intrinsics,
    };

    result = xrGetCameraImageDataBD(captureSession, image.imageId, (XrCameraImageDataBaseHeaderBD *)&imageData);
    if (result == XR_SUCCESS)
    {
        // Process image data, intrinsics and extrinsics
    }

    // Release image
    xrReleaseCameraImageBD(captureSession, image.imageId);
    lastCaptureTime = image.captureTime;
}

// Cleanup
xrEndCameraCaptureBD(captureSession);
xrDestroyCameraCaptureSessionBD(captureSession);
xrDestroyCameraDeviceBD(cameraDevice);
